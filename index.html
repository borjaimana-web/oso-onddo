ℹ️ Mapas locales

Selecciona un archivo .osm desde «Cartografía». El archivo se procesa directamente en este dispositivo y no se sube a ningún servidor.

Los mapas locales se superponen a la cartografía base; el más reciente tiene prioridad visual. Puedes activarlos, desactivarlos o eliminarlos desde Cartografía. Para mostrar el mapa base online necesitas conexión a Internet.

Se admiten archivos .osm en formato XML; no se admiten .pbf ni .mbtiles.
